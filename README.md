# 🤖 Target Tracking Assistant Cart

Двоконтурна система керування для автономного роботизованого візка-помічника, який слідує за людиною на дистанції **1.0–1.5 м**, перевозить вантаж **5–10 кг** та уникає зіткнень із перешкодами.

## 🏗️ Архітектура системи
1. **Master (Raspberry Pi 4, Debian Bookworm 64-bit, Python 3):**
   - Захоплення відео `640x480 @ 30 FPS` через `Picamera2` (CSI-камера **Waveshare OV5647**, 60.6° FOV) з автоматичним переходом у `DEMO_SIMULATOR`, якщо камера не підключена.
   - ШІ-детекція та трекінг людини (`YOLOv8n` / `MediaPipe`).
   - Два ПІД-регулятори: кутовий (`Steering` по осі `cx`) та лінійний (`Speed` по `box_height` для дистанції `1.0–1.5 м`).
   - Двосторонній UART-протокол по USB (`/dev/ttyUSB0`, `115200 baud`): `<CMD,L_PWM,R_PWM>\n` та `<STAT,D1,D2,D3,D4,STATE>\n`.
   - Мобільний веб-інтерфейс на Flask (`порт 5000`) із MJPEG-відеопотоком, перемикачем `AUTO AI / MANUAL / STOP` та віртуальним джойстиком.
2. **Slave (ESP32 DevKit V1 30-pin, C++ / Arduino):**
   - Прошивка: [`esp32_firmware/esp32_slave.ino`](esp32_firmware/esp32_slave.ino)
   - Керування 2× драйверами **BTS7960 43A** (ШІМ **20 кГц**, плавний розгін/гальмування для черв'ячних мотор-редукторів **JGY-370 12V 160 RPM**).
   - Опитування 4× ультразвукових датчиків **HC-SR04** (миттєва зупинка руху вперед при перешкоді `< 35 см`) та Watchdog `400 мс`.
